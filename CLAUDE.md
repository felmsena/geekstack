# GeekStack — Backend

Rails 7.2 + Spree 5.4.1 (headless commerce API).

## Branch naming

Use descriptive, lowercase kebab-case names with a type prefix:

| Type | Ejemplo |
|------|---------|
| `feature/` | `feature/spree-setup`, `feature/product-api` |
| `fix/` | `fix/auth-bug`, `fix/cors-headers` |
| `chore/` | `chore/update-deps`, `chore/ci-config` |
| `refactor/` | `refactor/order-model` |

No usar prefijo `claude/` ni sufijos aleatorios.
